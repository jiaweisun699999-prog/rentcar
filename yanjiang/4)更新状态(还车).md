# 订单模块：更新状态(还车)完整前后端生命周期流程

这是一次经典的“前后端分离架构全生命周期”剖析。我们将以点击“我要还车”这个动作为例，顺着数据的流向，把项目里的相关代码完完整整地串联起来。

以下是完整的 9 个详细步骤：

## 第一阶段：前端发起与“出境安检”

### 1. 前端点击触发 (`Orders.vue`)
当用户在订单列表点击“我要还车”按钮时，触发了 `handleReturn` 方法：
```javascript
// Orders.vue (大约 270 行)
const handleReturn = async (order) => {
  try {
    // axios 触发 PUT 请求，携带订单号和目标状态码 3 (待还车结算)
    await request.put('/order/status/update', {
      orderNo: order.orderId,
      status: 3
    });
    // ... 等待请求返回
  }
}
```

### 2. 前端请求拦截器 (`src/utils/request.js`)
同样经过 `request` 拦截器：
```javascript
// request.js
service.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token');
    if (token) config.headers['Authorization'] = 'Bearer ' + token;
    return config; 
  }
);
```

### 3. 网络传输
带有 JSON 报文体和 Token 请求头的 HTTP PUT 报文发往后端。

## 第二阶段：后端鉴权与业务处理

### 4. 后端拦截器鉴权 (`JwtInterceptor.java`)
同样被 `JwtInterceptor` 拦截鉴权：
```java
// JwtInterceptor.java
public boolean preHandle(...) throws Exception {
    String token = request.getHeader("Authorization");
    if (StringUtils.hasText(token) && token.startsWith("Bearer ")) {
        // ... 解析 Token，存入 UserContext
        return true; 
    }
    response.setStatus(401);
    return false;
}
```

### 5. Controller 分发业务 (`OrderController.java`)
请求到达修改状态的 PUT 接口：
```java
// OrderController.java
@PutMapping("/order/status/update")
public Result<Void> updateStatus(@RequestBody OrderStatusUpdateDto dto) {
    try {
        // 调用Service层更新指定订单的状态
        carOrderService.updateOrderStatus(dto.getOrderNo(), dto.getStatus());
        return Result.success(null);
    } catch (Exception e) {
        return Result.error(e.getMessage());
    }
}
```

### 6. Service 操作数据库 (`CarOrderServiceImpl.java`)
```java
// CarOrderServiceImpl.java (大约 180 行)

    }
}
```

### 7. 请求结束后的清理工作
```java

public void afterCompletion(...) {

```

## 第三阶段：前端接收与渲染

### 8. 前端响应拦截器解包 (`src/utils/request.js`)
处理后端返回结果：
```javascript
// request.js
service.interceptors.response.use(
  response => {
    const res = response.data;
    if (res.code === 200) {
      return res.data; 
    } else {
      ElMessage.error(res.msg); 
      return Promise.reject(new Error(res.msg));
    }
  }
);
```

### 9. 前端业务逻辑收尾 (`Orders.vue`)
流程回到 `Orders.vue`：
```javascript
// Orders.vue
const handleReturn = async (order) => {
  try {
    await request.put('/order/status/update', { ... });
    
    // 弹出绿色成功提示
    ElMessage.success('还车申请发起成功，正在等待门店核验结算！');
    
    // 重新拉取最新的订单列表数据，Vue 自动重绘页面以反映状态的变化
    fetchOrders(); 
  } catch (error) {
    console.error(error);
  }
};
```
