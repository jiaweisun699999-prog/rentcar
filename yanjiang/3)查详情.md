# 订单模块：查详情完整前后端生命周期流程

这是一次经典的“前后端分离架构全生命周期”剖析。我们将以“查看明细”这个动作为例，顺着数据的流向，把项目里的相关代码完完整整地串联起来。

以下是完整的 9 个详细步骤：

## 第一阶段：前端发起与“出境安检”

### 1. 前端点击触发 (`Orders.vue`)
当用户点击某一条订单的“查看明细”按钮时，触发了 `handleDetail` 方法：
```javascript
// Orders.vue (大约 290 行)
const handleDetail = async (order) => {
  detailVisible.value = true; // 打开详情弹窗
  detailLoading.value = true; // 开启弹窗内部的骨架屏/loading
  try {
    // 携带 orderNo 参数发送 GET 请求
    const res = await request.get('/order/detail', { params: { orderNo: order.orderId } });
    // ... 后续代码先挂起，等待请求返回
  }
}
```

### 2. 前端请求拦截器 (`src/utils/request.js`)
在 Axios 发送请求之前，必定会经过 `request` 拦截器：
```javascript
// request.js
service.interceptors.request.use(
  config => {
    // 从本地存储获取 token 并放入请求头
    const token = localStorage.getItem('token');
    if (token) {
      config.headers['Authorization'] = 'Bearer ' + token;
    }
    return config; // 放行请求
  }
);
```

### 3. 网络传输
带有查询参数（`?orderNo=xxx`）和 Token 请求头的 HTTP GET 报文，通过互联网飞向后端服务器。

## 第二阶段：后端鉴权与业务处理

### 4. 后端拦截器鉴权 (`JwtInterceptor.java`)
请求到达 Spring Boot 后，被 `JwtInterceptor` 拦截：
```java
// JwtInterceptor.java
public boolean preHandle(...) throws Exception {
    String token = request.getHeader("Authorization");
    if (StringUtils.hasText(token) && token.startsWith("Bearer ")) {
        token = token.substring(7);
        try {
            Claims claims = jwtUtils.parseToken(token);
            // 提取用户ID并存入上下文
            UserContext.setUserId(Long.valueOf(claims.getSubject()));
            return true; // 校验通过放行
        } catch (Exception e) {}
    }
    response.setStatus(401); // 拒绝访问
    return false;
}
```

### 5. Controller 分发业务 (`OrderController.java`)
请求通过拦截器，来到了详情查询的 GET 接口：
```java
// OrderController.java
@GetMapping("/order/detail")
public Result<OrderDetailVo> detail(@RequestParam("orderNo") String orderNo) {
    // 调用Service层查询订单详细信息
    OrderDetailVo detail = carOrderService.getOrderDetail(orderNo);
    
    if (detail == null) {
        return Result.error("订单不存在或无权查看");
    }
    // 返回成功结果并附带查询到的详细数据
    return Result.success(detail);
}
```

### 6. Service 操作数据库 (`CarOrderServiceImpl.java`)
```java
// CarOrderServiceImpl.java
public OrderDetailVo getOrderDetail(String orderNo) {
    // 去数据库查询订单实体
    CarOrder order = this.getOne(new LambdaQueryWrapper<CarOrder>().eq(CarOrder::getOrderNo, orderNo));
    if (order == null) return null;
    
    // 组装返回给前端的详细视图对象 (VO)
    OrderDetailVo vo = new OrderDetailVo();
    vo.setOrderNo(order.getOrderNo());
    // ... 将所需字段逐个填充进 VO
    return vo; 
}
```

### 7. 请求结束后的清理工作
请求结束后清理线程上下文：
```java
// JwtInterceptor.java
public void afterCompletion(...) {
    UserContext.removeUserId(); 
}
```

## 第三阶段：前端接收与渲染

### 8. 前端响应拦截器解包 (`src/utils/request.js`)
后端返回数据抵达前端，Axios 响应拦截器接手：
```javascript
// request.js
service.interceptors.response.use(
  response => {
    const res = response.data;
    if (res.code === 200) {
      return res.data; // 脱掉 {code, message} 包装，只返回核心详情对象
    } else {
      ElMessage.error(res.msg); 
      // 处理 401 登出等...
      return Promise.reject(new Error(res.msg));
    }
  }
);
```

### 9. 前端业务逻辑收尾 (`Orders.vue`)
流程回到 `Orders.vue`：
```javascript
// Orders.vue
const handleDetail = async (order) => {
  // ...
  try {
    const res = await request.get('/order/detail', { params: { orderNo: order.orderId } });
    
    // 把解包后的详细对象赋值给页面的变量
    orderDetail.value = res; 
    
    // Vue 侦测到 orderDetail 变化，自动将详细数据渲染到弹窗的 HTML 中
  } catch (error) {
    ElMessage.error('获取订单详情失败');
    detailVisible.value = false;
  } finally {
    // 关掉加载动画，展示详细内容
    detailLoading.value = false;
  }
};
```
