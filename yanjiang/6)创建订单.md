# 订单模块：创建订单完整前后端生命周期流程

这是一次经典的“前后端分离架构全生命周期”剖析。我们将以用户在预结算界面点击“确认提交订单”这个动作为例，顺着数据的流向，把项目里的相关代码完完整整地串联起来。

以下是完整的 9 个详细步骤：

## 第一阶段：前端发起与“出境安检”

### 1. 前端点击触发 (`CarSearch.vue`)
当用户确认账单无误，点击“确认提交订单”时，触发 `submitOrder` 方法：
```javascript
// CarSearch.vue (大约 360 行)
const submitOrder = async () => {
  try {
    // 再次组装车辆、时间等核心参数，发送 POST 请求
    await request.post('/order/create', {
      carModelId: selectedCar.value.id,
      pickupStoreId: searchParams.value.storeId,
      // ...
    });
    // ...
  }
}
```

### 2. 前端请求拦截器 (`src/utils/request.js`)
```javascript
// request.js
service.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token');
    if (token) config.headers['Authorization'] = 'Bearer ' + token;
    return config; 
  }
);
```

### 3. 网络传输
包含真实下单参数的 HTTP POST 报文飞往后端。这也是订单从无到有的关键一步。

## 第二阶段：后端鉴权与业务处理

### 4. 后端拦截器鉴权 (`JwtInterceptor.java`)
```java
// JwtInterceptor.java
public boolean preHandle(...) throws Exception {
    String token = request.getHeader("Authorization");
    if (StringUtils.hasText(token) && token.startsWith("Bearer ")) {
        // 解析出下单人的身份 userId，存入 UserContext
        return true; 
    }
    response.setStatus(401);
    return false;
}
```

### 5. Controller 分发业务 (`OrderController.java`)
请求到达创建订单的入口：
```java
// OrderController.java (大约 95 行)
@PostMapping("/order/create")
public Result<String> create(@RequestBody OrderCreateDto dto) {
    try {
        // 调用Service层执行创建订单的复杂业务逻辑
        String orderNo = carOrderService.createOrder(dto);
        // 成功则返回新生成的订单号
        return Result.success(orderNo);
    } catch (Exception e) {
        // 捕获可能出现的异常（库存不足、状态不对等）反馈给前端
        return Result.error(e.getMessage());
    }
}
```

### 6. Service 真正落库 (`CarOrderServiceImpl.java`)
```java
// CarOrderServiceImpl.java
public String createOrder(OrderCreateDto dto) {
    // 1. 获取当前用户
    Long userId = UserContext.getUserId();
    
    // 2. 二次核算金额 (调用 previewOrder 方法里相同的算钱逻辑，防篡改)
    OrderPreviewVo bill = previewOrder(dto);
    
    // 3. 构建数据库实体 CarOrder
    CarOrder order = new CarOrder();
    order.setOrderNo(generateOrderNo()); // 生成全局唯一订单流水号
    order.setUserId(userId);
    order.setStatus(0); // 初始状态为 0:待支付
    // ... 塞入各种金额和时间
    
    // 4. 调用框架保存到 MySQL
    this.save(order);
    
    // 5. （可选）操作其他表：锁定车辆库存等
    
    return order.getOrderNo();
}
```

### 7. 请求结束后的清理工作
```java
// JwtInterceptor.java
```

## 第三阶段：前端接收与渲染

### 8. 前端响应拦截器解包 (`src/utils/request.js`)
```javascript
// request.js
service.interceptors.response.use(
  response => {
    const res = response.data;
    if (res.code === 200) {
      return res.data; // 返回刚才后端的那个 String orderNo
    } else {
      ElMessage.error(res.msg); 
      return Promise.reject(new Error(res.msg));
    }
  }
);
```

### 9. 前端业务逻辑收尾 (`CarSearch.vue`)
流程回到 `CarSearch.vue`：
```javascript
// CarSearch.vue
const submitOrder = async () => {
  try {
    await request.post('/order/create', { ... });
    
    // 1. 下单成功，弹出绿色通知
    ElMessage.success('订单创建成功！');
    
    // 2. 关闭预结算弹窗
    previewDialogVisible.value = false;
    
    // 3. 使用路由 API，将页面跳转到“我的订单”页。
    // 在我的订单页面，就会自动触发上文讲解的“查订单列表”流程！完美衔接！
    router.push('/orders');
  } catch (error) {
    console.error(error);
  }
};
```
