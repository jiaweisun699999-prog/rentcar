# 订单模块：下单预览完整前后端生命周期流程

这是一次经典的“前后端分离架构全生命周期”剖析。我们将以选好车点击“立即预订”进入预结算页面为例，顺着数据的流向，把项目里的相关代码完完整整地串联起来。

以下是完整的 9 个详细步骤：

## 第一阶段：前端发起与“出境安检”

### 1. 前端点击触发 (`CarSearch.vue`)
当用户在搜车页点击某辆车的“立即预订”按钮时，触发了 `openOrderPreview` 方法：
```javascript
// CarSearch.vue (大约 333 行)
const openOrderPreview = async (car) => {
  // ... 显示弹窗与加载动画
  try {
    // 组装车辆ID、取还车时间等参数，发送 POST 请求
    const res = await request.post('/order/preview', {
      carModelId: car.id,
      pickupStoreId: searchParams.value.storeId,
      // ...
    });
    // ...
  }
}
```

### 2. 前端请求拦截器 (`src/utils/request.js`)
```javascript
// request.js
service.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token');
    if (token) config.headers['Authorization'] = 'Bearer ' + token;
    return config; 
  }
);
```

### 3. 网络传输
带着即将下单的各项参数，附带 Token 的 HTTP POST 报文飞往后端。

## 第二阶段：后端鉴权与业务处理

### 4. 后端拦截器鉴权 (`JwtInterceptor.java`)
```java
// JwtInterceptor.java
public boolean preHandle(...) throws Exception {
    String token = request.getHeader("Authorization");
    if (StringUtils.hasText(token) && token.startsWith("Bearer ")) {
        // ... 解析 Token，存入 UserContext
        return true; 
    }
    response.setStatus(401);
    return false;
}
```

### 5. Controller 分发业务 (`OrderController.java`)
请求进入预览接口：
```java
// OrderController.java (大约 83 行)
@PostMapping("/order/preview")
public Result<OrderPreviewVo> preview(@RequestBody OrderCreateDto dto) {
    // 调用Service层计算各项费用，并返回预览视图对象
    return Result.success(carOrderService.previewOrder(dto));
}
```

### 6. Service 计算核心费用 (`CarOrderServiceImpl.java`)
这里的业务极重，需要核算各项金额，但并不会把数据真正写入订单表：
```java
// CarOrderServiceImpl.java 
public OrderPreviewVo previewOrder(OrderCreateDto dto) {
    // 1. 查询车辆、门店等基础数据

    // 4. 计算保险费、手续费、押金等...
    
    // 组装成前端能看懂的预结算明细单并返回
    OrderPreviewVo vo = new OrderPreviewVo();
    vo.setRentDays(rentDays);
    vo.setTotalAmount(totalAmount);
    // ...

```

## 第三阶段：前端接收与渲染

### 8. 前端响应拦截器解包 (`src/utils/request.js`)
```javascript
// request.js
service.interceptors.response.use(
  response => {
    const res = response.data;
    if (res.code === 200) {
      return res.data; // 返回 OrderPreviewVo 这个 JSON 实体
    } else {
      ElMessage.error(res.msg); 
      return Promise.reject(new Error(res.msg));
    }
  }
);
```

### 9. 前端业务逻辑收尾 (`CarSearch.vue`)
流程回到 `CarSearch.vue`：
```javascript
// CarSearch.vue
const openOrderPreview = async (car) => {
  try {
    const res = await request.post('/order/preview', { ... });
    
    // 后端算好的各项费用明细赋值给 previewData 变量
    previewData.value = res;
    
    // Vue 侦测到变量变化，将数据渲染进核对账单的弹窗模板里，给用户看最终要花多少钱
  } catch (error) {
    previewDialogVisible.value = false;
  } finally {
    previewLoading.value = false; // 取消加载动画
  }
};
```
