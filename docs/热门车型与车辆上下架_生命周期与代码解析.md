# 三、模块一：热门推荐车型

## 3.1 完整生命周期

```text
[1] 管理员上架车型 + 投放实体车辆
[2] 用户打开首页 Home.vue
[3] 前端调 GET /api/store/list 拿门店，生成城市按钮
[4] 前端调 GET /api/car/model/list?page=1&pageSize=8
[5] 后端从 car_model 按创建时间倒序取
[6] 后端用 car_instance 补充日租金、车牌
[7] 后端用 store_info 补充城市
[8] 返回 records 给前端
[9] 前端渲染卡片
[10] 用户切换城市 -> 重新调步骤[4]带 cityName
[11] 用户点击卡片 -> 弹出详情
[12] 点击预订 -> 跳转 /search?storeId&startTime&endTime&autoBookModelId
```

### 全国模式


实际 SQL：

`@TableLogic` 让 MyBatis-Plus 自动追加 `is_deleted = 0`。

### 城市模式

```java
List<StoreInfo> stores = storeInfoMapper.selectList(

List<Long> storeIds = stores.stream().map(StoreInfo::getId).toList();

LambdaQueryWrapper<CarInstance> iw = new LambdaQueryWrapper<>();
```

### 取最低日租金

```java
private Map<Long, BigDecimal> getMinDailyPriceMap(List<Long> modelIds) {
    List<CarInstance> instances = carInstanceMapper.selectList(
        new LambdaQueryWrapper<CarInstance>().in(CarInstance::getModelId, modelIds));
    return instances.stream()
        .filter(i -> i.getDailyRentPrice() != null)
        .collect(Collectors.groupingBy(
            CarInstance::getModelId,
            Collectors.collectingAndThen(Collectors.toList(), this::getMinDailyPrice)
        ));
}
```

按 `modelId` 分组，每组取最低 `dailyRentPrice`。

### VO 组装与兜底

```java
private CarModelListVo buildModelListVo(CarModel m, BigDecimal price,
                                        String plate, String city, Long storeId) {
    CarModelListVo vo = new CarModelListVo();
    vo.setId(m.getId());
    vo.setBrandSeries(m.getBrandSeries());
    vo.setCarType(m.getCarType());
    vo.setSeatsDoors(m.getSeatsDoors());
    vo.setMainImage(m.getMainImage());
    if (price == null || price.compareTo(BigDecimal.ZERO) == 0) {
        price = BigDecimal.valueOf(180L + (m.getId() % 5) * 40L);  // 价格兜底
    }
    vo.setDailyPrice(price);
    if (!StringUtils.hasText(plate)) plate = generatePlateForModel(m.getId());  // 车牌兜底
    vo.setLicensePlate(plate);
    if (!StringUtils.hasText(city)) city = "上海市";  // 城市兜底
    vo.setLocationCity(city);
    vo.setStoreId(storeId);
    vo.setCreateTime(m.getCreateTime());
    return vo;
}
```

即使车型没有实体车辆，前台也能完整显示。

## 4.3 后端实现：上传接口 `UploadController`

```java
@PostMapping("/upload")
public Result<UploadResVo> upload(@RequestParam("file") MultipartFile file, HttpServletRequest request) {
    if (file == null || file.isEmpty()) throw new RuntimeException("上传文件不能为空");
    if (file.getSize() > MAX_FILE_SIZE) throw new RuntimeException("文件大小不能超过10MB");

    String extension = StringUtils.getFilenameExtension(file.getOriginalFilename()).toLowerCase();
    if (!ALLOWED_EXTENSIONS.contains(extension)) throw new RuntimeException("不支持的文件格式");

    String datePath = LocalDate.now().toString();
    Path uploadDir = Paths.get(System.getProperty("user.dir"), "uploads", datePath);
    Files.createDirectories(uploadDir);

    String filename = UUID.randomUUID().toString().replace("-", "") + "." + extension;
    file.transferTo(uploadDir.resolve(filename).toFile());

    UploadResVo resVo = new UploadResVo();
    resVo.setUrl(buildFileUrl(request, datePath, filename));
    return Result.success("上传成功", resVo);
}
```

逐行解释：

- **`@RequestParam("file")`**：接收 FormData 中名为 `file` 的字段
- **`MultipartFile`**：Spring 的文件上传对象
- **`MAX_FILE_SIZE = 10MB`**：大小限制
- **`ALLOWED_EXTENSIONS`**：白名单扩展名
- **`LocalDate.now()`**：按日期分目录 `uploads/2026-05-26/`
- **`UUID`**：随机文件名避免重名
- **`buildFileUrl`**：返回 `http://localhost:8080/uploads/.../xxx.png`

静态资源映射在 `WebMvcConfig`：

```java
registry.addResourceHandler("/uploads/**")
        .addResourceLocations("file:" + System.getProperty("user.dir") + "/uploads/");
```

```java
@Override
public void addModel(CarModelAddDto addDto) {
    checkModelAddParams(addDto);
    CarModel model = new CarModel();
    model.setBrandSeries(addDto.getBrandSeries());
    model.setCarType(addDto.getCarType());
    model.setSeatsDoors(addDto.getSeatsDoors());

private void checkModelAddParams(CarModelAddDto addDto) {
```

# 五、模块三：车辆下架

## 5.1 下架车型（SPU）生命周期

```text
[1] 管理员在 SPU Tab 看到车型列表

[3] 弹出 ElMessageBox 确认框
```

```js
    ElMessage.success('车型下架封档成功');
    fetchCars();
  }).catch(() => {});
};
```

逐行解释：

- **`ElMessageBox.confirm`**：弹出确认框，返回 Promise
- **`.then(async () => {...})`**：用户点确认才执行
- **`.catch(() => {})`**：用户取消时静默处理
- **模板字符串**：`` `/car/model/delete/${id}` `` 拼接路径
- **`request.delete`**：HTTP DELETE 请求

表格中触发：

```vue
<el-button size="small" type="danger" link @click="deleteCar(scope.row.id)">
  下架该车型
</el-button>
```

### Service

```java
    this.removeById(id);
}
```

`this.removeById(id)` 是 MyBatis-Plus 自带方法。

## 5.4 逻辑删除原理

`CarModel` 实体声明：

```java
@Data
@TableName("car_model")
public class CarModel {
    @TableId(type = IdType.AUTO)
    private Long id;
    private String brandSeries;
    private String carType;
    // ...
    @TableLogic
    private Integer isDeleted;
}
```

- **`@TableLogic`**：标记该字段为逻辑删除标记
- 调用 `removeById` 时，MyBatis-Plus 不发 DELETE，而是发 UPDATE

实际 SQL：

```sql
UPDATE car_model SET is_deleted = 1 WHERE id = ?
```

后续所有查询自动追加 `WHERE is_deleted = 0`，所以被下架的车型：

- 首页热门车型不再展示
- 后台车型列表不再展示
- 推荐接口不再返回
- 数据仍保留在数据库中，便于历史订单追溯

## 6.1 上架 → 热门推荐

# 七、常见问题排查

## 7.1 上架后首页看不到？

- 后端是否启动
- 数据库连接是否正常
- 是否选择了城市，且该车型在该城市没有实体车辆
- 浏览器 Network 看 `/api/car/model/list` 返回

## 7.2 图片上传成功但首页不显示？

- 检查 `car_model.main_image` 是否为有效 URL
- 后端 `WebMvcConfig` 是否配置了 `/uploads/**` 静态资源映射
- 静态文件是否在 `uploads/yyyy-MM-dd/` 目录下

## 7.3 下架后数据还在数据库？

正常。逻辑删除只把 `is_deleted` 改为 1，物理记录保留。

可手动恢复：

```sql
UPDATE car_model SET is_deleted = 0 WHERE id = ?;
```

## 7.4 点击预订找不到车？

- 该车型没有对应实体车辆
- 实体车辆不在跳转的门店
- 时间段冲突
- 车辆状态为准备中或维修中

# 八、总结

| 模块 | 入口 | 接口 | 后端方法 | 数据库操作 |
|---|---|---|---|---|
| 热门推荐 | Home.vue | GET /car/model/list | getModelList | SELECT car_model + car_instance + store_info |
| 上架车型 | Admin.vue submitCar | POST /car/model/add | addModel | INSERT car_model |
| 上传图片 | Admin.vue uploadCarImage | POST /upload | upload | 写文件到 uploads/ |
| 投放实体 | Admin.vue submitCarInstance | POST /car/instance/add | addInstance | INSERT car_instance |
| 下架车型 | Admin.vue deleteCar | DELETE /car/model/delete/{id} | deleteModel | UPDATE is_deleted=1 |
| 下架实体 | Admin.vue deleteCarInstance | DELETE /car/instance/delete/{id} | removeById | UPDATE is_deleted=1 |

核心思想：

- **车型 SPU** 负责"是什么车"
- **实体 SKU** 负责"哪辆车、多少钱、停在哪"
- **门店** 负责"城市归属"
- **逻辑删除** 保证数据可追溯，不会破坏历史订单
